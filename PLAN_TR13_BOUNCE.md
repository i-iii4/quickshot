## Задача

Сделать поведение ленты на границах неотличимым от системного скролла:
отскок от края с глубиной, зависящей от скорости, и возврат пружиной без
разрыва скорости. Сейчас инерция глушится у края в стену, а пружина
возврата стартует с нулевой скорости — это и читается как «нет резины,
нет замедления».

## Эталонная модель (валидирована: UIScrollView, WWDC 2018)

Три режима, переходы без разрыва позиции и скорости:

1. ПАЛЕЦ (event.phase != []): лента один к одному с дельтами; за краем —
   сопротивление формулой Apple `(x·d·c)/(d + c·x)`, c = 0.55,
   d = длина карточки. УЖЕ РЕАЛИЗОВАНО, не трогать.
2. ИНЕРЦИЯ ВНУТРИ ГРАНИЦ (event.momentumPhase != []): применять дельты
   как есть — затухание уже посчитано системой. УЖЕ ТАК, не трогать.
3. ГРАНИЦА: три случая, все решаются одной пружиной (см. «Пружина»):
   а) инерция довезла до края: остаток скорости передаётся пружине —
      лента вылетает за край и возвращается (отскок). Сейчас вместо
      этого мгновенный clamp — это и есть главный дефект;
   б) палец отпущен, лента растянута за край: пружина к границе с
      начальной скоростью, равной скорости жеста в момент отпускания.
      Сейчас пружина стартует с нулевой скорости;
   в) палец отпущен внутри границ: ничего не делать, ждать инерцию.

## Пружина

Критически задемпфированная, с начальным смещением и НАЧАЛЬНОЙ СКОРОСТЬЮ:

    x(t) = (x0 + (v0 + omega * x0) * t) * exp(-omega * t)

где x0 — текущий уход за край (0 в случае «а»), v0 — скорость в точке
передачи (знак: наружу положительный), omega = 2*pi / 0.4 (отклик 0.4 с —
параметр Apple для перемещения объектов, уже задокументирован в TR-13).
Никакого перелёта колебаниями: при x0 = 0 и v0 > 0 кривая сама выходит на
пик v0/(omega*e) и монотонно возвращается к нулю — это и есть отскок,
глубина автоматически пропорциональна скорости.

Длительность прогона аниматора: 0.7 с (хвост < 0.5% пути). Каждый кадр:
offset = граница + x(t); по завершении offset = граница точно.

## Трекер скорости

Скорость считается из событий: v = дельта / (timestamp события - timestamp
предыдущего). Сглаживание: экспоненциальное, alpha = 0.3, чтобы одиночный
рваный кадр не задавал скорость передачи. Хранится в менеджере рядом с
обработкой прокрутки; сбрасывается при began.

Скорость измеряется В ВИДИМЫХ координатах (после преобразования защёлки),
потому что пружина работает с видимым смещением. Практически: считать
дельту видимого смещения за событие (offset до/после detent.apply) и
делить на dt.

## Приёмка

Автоматическая (добавить в `Tests/TrayScrollModelTests.swift` или рядом,
прогон `python3 scripts/run-one.py <Suite>.swift`; живые UI-тесты
ЗАПРЕЩЕНЫ без явного разрешения заказчика в момент запуска):
1. Непрерывность: в точке передачи «инерция -> пружина» позиция
   непрерывна, скорость непрерывна (численно, допуск 1e-3).
2. Отскок существует: при v0 > 0 максимум x(t) > 0 и равен v0/(omega*e)
   (допуск 1%); при v0 = 0 и x0 = 0 пружина не двигает ленту.
3. Возврат: x(0.7) < 0.005 * пик; знак x(t) не меняется (нет колебаний).
4. Пропорциональность: пик отскока при 2*v0 ровно вдвое больше пика при
   v0.
5. Защёлка: её существующие тесты проходят без изменений; diff по
   `TrayDetentModel` пуст.

Ручная приёмка заказчиком: бросок ленты в край — виден отскок, глубина
зависит от силы броска; медленное подведение к краю — без отскока;
отпускание растянутой ленты — возврат без рывка, продолжающий движение
руки.
